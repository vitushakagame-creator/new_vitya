VITYA NEWS 2В — ИНСТРУКЦИЯ

Главные файлы сайта (index.html, style.css, app.js, server.js) находятся в корне проекта рядом друг с другом. Сервер автоматически обслуживает сайт и обнаруживает файлы в папках public.

ЗАПУСК
1. Установи Node.js 18 или новее: https://nodejs.org/
2. В папке проекта выполни: npm start
3. Открой http://localhost:3000

ПАПКИ, КОТОРЫЕ ЗАПОЛНЯЮТСЯ АВТОМАТИЧЕСКИ
- public/Mini-Videos/ — положи сюда MP4, WebM, MOV или M4V. Они автоматически появятся во вкладке «Мини-видосики». Список JSON редактировать не нужно.
- public/Programs/ — положи сюда программы и файлы. Они автоматически появятся во вкладке «Программы и файлы» с кнопкой скачивания. Можно создавать подпапки.
- public/Materials/ — место для дополнительных материалов на будущее.
- data/site-data.json — серверная база новостей, сообщений и профилей. Не публикуй настоящие данные в открытом репозитории.

ПУБЛИКАЦИЯ
Используй хостинг, который запускает Node.js и хранит папку data на постоянном диске. Команда запуска: npm start. GitHub Pages не запускает server.js.

ВХОД
Выбери устройство, роль, придумай ник и личный код не короче 4 символов. Для повторного входа используй те же данные. Это базовая система: перед публичным использованием нужны ограничение попыток входа, хеширование кодов, HTTPS и резервные копии.
